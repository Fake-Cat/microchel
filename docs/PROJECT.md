# docs/PROJECT.md — описание проекта Microchel

## Назначение

Микрочел — анимированный Desktop Pet для Linux с автономным ИИ-агентом. Живёт на рабочем столе, ведёт себя как самостоятельный персонаж (ходьба, сон, еда, эмоции), выполняет поручения пользователя на естественном языке, мониторит систему и работает круглосуточно.

Ориентир — VPet-Simulator (https://github.com/LorisYounger/VPet), но реализация самостоятельная (Python + PySide6), не порт Windows-приложения.

## Основные функции

1. **Персонаж**: прозрачное окно без рамки, 2D-спрайтовые анимации (IDLE, WALK, SLEEP, SIT, COFFEE, THINKING, TALKING, HAPPY, ANGRY, PANIC и др., всего 15 базовых), реакция на клики/курсор/перетаскивание, контекстное меню, always-on-top.
2. **Поведение**: FSM с автономным выбором бытовых действий, приоритетная анимационная система, event-driven.
3. **ИИ-агент**: поручения на естественном языке, LLM (Gemini/Groq/OpenRouter, бесплатные квоты), tool registry с permission policy, многошаговое выполнение с лимитами.
4. **Интеграция с Linux**: файлы, терминал, запуск программ, SSH, системные команды — через разрешённые инструменты.
5. **Мониторинг**: метрики, расписания, алерты — работает без LLM.
6. **Память**: SQLite — история, задачи, долговременная память.
7. **Голос** (поздние этапы): STT/TTS, wake word.

## Пользовательские сценарии

- Пользователь видит персонажа на рабочем столе, таскает его, кликает — получает реакции и меню.
- Пользователь пишет «прочитай последние логи nginx» — агент выбирает инструменты и выполняет (с подтверждением для опасных действий).
- Персонаж сам решает: пройтись, выпить кофе, поспать; при событии системы — реагирует анимацией и уведомлением.
- Пользователь настраивает автозапуск, расписание проверок, доступные инструменты.

## Функциональные требования

- FR-1: Отображение персонажа в прозрачном всегда-поверх-окне с alpha-прозрачностью.
- FR-2: Проигрывание спрайтовых анимаций с FPS/loop/переходами и кэшированием.
- FR-3: FSM поведения (idle, walk, sleep, sit, coffee, thinking + события).
- FR-4: Взаимодействие: drag-and-drop, клики, контекстное меню, ограничение экраном.
- FR-5: Приём поручений текстом, выполнение через реестр инструментов с лимитами шагов.
- FR-6: Permission policy: опасные операции требуют подтверждения.
- FR-7: SQLite-память: история, задачи, события, настройки.
- FR-8: Мониторинг системы без LLM, алерты.
- FR-9: Масштабирование, автозапуск.

## Нефункциональные требования

- NF-1: Работа на Raspberry Pi 4B (4 GB RAM, ARM64): память в IDLE минимальна, нет блокировок главного потока Qt.
- NF-2: x86-64 и ARM64 с первого дня, без x86-only зависимостей.
- NF-3: 24/7 работа, устойчивость к сбоям LLM-API (пит не останавливается).
- NF-4: Старт приложения — секунды, потребление в IDLE — фоновое, без высокой CPU.
- NF-5: Воспроизводимая установка, фиксированные зависимости.

## Технические ограничения

- Python ≥ 3.11, PySide6/Qt, без Electron и Chromium.
- Оконный протокол: X11 предпочтителен (целевая RPi), разработка может идти под Wayland — проверять совместимость.
- LLM — только облачные API с бесплатными квотами; локальных больших моделей нет.
- Лицензии: анимации VPet имеют отдельные условия — учитывать при добавлении ресурсов.

## Критерии готовности проекта

- [ ] Персонаж плавно анимируется на рабочем столе Ubuntu и Raspberry Pi OS.
- [ ] Пользовательское поручение выполняется агентом через инструменты с подтверждением опасных действий.
- [ ] Мониторинг и память работают без сети и без LLM.
- [ ] Приложение живёт 24/7 без утечек памяти (проверено профайлером).
- [ ] Установка на чистую Raspberry Pi OS, автозапуск, тесты пройдены.
- [ ] Документация актуальна, все проверки описаны в TESTING.md.
