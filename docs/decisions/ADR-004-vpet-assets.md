# ADR-004: Ресурсы VPet — условия использования анимаций

**Статус:** принят (2026-10-08)

## Контекст

Концепция требует исследовать лицензии VPet, не включать материалы с неустановленными правами и различать лицензию кода и графики.

## Что установлено (см. RESEARCH_VPET.md)

- **Код** VPet: Apache-2.0 (LICENSE в корне репозитория).
- **Анимации персонажа** (`VPet-Simulator.Windows/mod/0000_core/pet/vup`):版权归 VUP-Simulator制作组, отдельные условия в README:
  - некоммерческое использование — бесплатно при указании источника и ссылки на репозиторий VPet;
  - коммерческое — дополнительные требования (уведомление, письмо автору, запрет продажи анимаций);
  - распространение файлов — только с полным указанием условий и без платы;
  - моды сторонних авторов — свои условия.

## Решение

1. **Ни один чужой графический файл не коммитится** в репозиторий до письменного решения пользователя.
2. Для разработки движка (PHASE 1–2) используются **временные собственные тестовые изображения** (концепция допускает).
3. Если пользователь решит использовать анимации VPet: соблюдать некоммерческие условия — указание источника и ссылки в README/приложении; зафиксировать это отдельным ADR.
4. Для свободного распространения — своя графика (PHASE 4).

## Причины

- Прямое требование концепции (разделы 5, 12).
- Условия анимаций несовместимы с неограниченным распространением.

## Последствия

- Нельзя массово конвертировать/скачивать анимации VPet «на будущее» — ждать решения.
- Движок делается универсальным, чтобы принять любой формат спрайтов.

## Ограничения

- Полный текст условий — в README VPet (раздел «动画版权声明与授权»); английская версия README_en.md может содержать уточнения — проверить перед использованием ресурсов.
