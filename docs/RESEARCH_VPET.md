## Организация анимационных ресурсов

Каталог персонажа: `VPet-Simulator.Windows/mod/0000_core/pet/vup/`

Иерархия (проверено по API):

```
vup/<Анимация>/<Состояние>/<Линия>/<кадры>
```

- **Анимации** (папки верхнего уровня): `BDay, Default, Drink, Eat, Think, Touch_Body, Touch_Head, WORK` и др. (по README — до 32 видов × 4 состояния × 3 типа).
- **Состояния**: например в `Default/` — `Happy, Ill, Nomal` (так в оригинале, опечатка вместо Normal), `PoorCondition`.
- **Линии**: `1, 2, 3` — варианты/линии анимации.
- **Кадры**: PNG, имена `_NNN_DDD.png`:
  - `NNN` — порядковый номер кадра с ведущими нулями (`000`, `001`, …);
  - `DDD` — длительность кадра в миллисекундах (`250`, `125`, `375`, …);
  - пример: `Default/Nomal/1/_000_250.png` (165 KB), `_001_125.png`, `_003_375.png`, … `_007_125.png`.
- Служебных json/xml с FPS в каталоге кадров нет — **тайминг зашит в имя файла** (см. ADR-005).

## Форматы и совместимость с Linux

- PNG с alpha — полностью переносим (Qt читает нативно).
- WPF/C#-код не переносится; логику загрузки/отображения воссоздаём в Python (PetLoader → наш animation loader, GraphCore → наш Animation Engine).
- Формат имён кадров и иерархию каталогов реализуем как основной формат ресурсов Микрочела.

## Лицензии

| Материал | Лицензия | Условия |
|---|---|---|
| Исходный код VPet | Apache-2.0 | свободное использование/модификация с сохранением NOTICE и лицензии |
| Анимации `mod/0000_core/pet/vup` (制作组 VUP-Simulator) | отдельные условия | **некоммерчески**: бесплатно, указать источник + ссылка на репозиторий VPet; **коммерчески**: уведомление в UI + письмо автору, запрет продажи файлов анимаций; **распространение**: только с полным указанием условий, без оплаты |
| Встроенные картинки программы | те же условия | Zip-галерея — без коммерции |
| Моды сторонних авторов | свои условия | проверять per-mod |

Вывод: код можно изучать и переиспользовать под Apache-2.0; графику в репозиторий не добавляем без решения пользователя (ADR-004).

## Возможности, которые берём в разработку

- Поведение персонажа (FSM, реакции) — воссоздаём своё (PHASE 3).
- Реакции на взаимодействие (Touch_Head, Touch_Body, поднятие, перетаскивание) — сохраняем и расширяем.
- Система модов/пользовательских ресурсов — позже, формат каталогов уже совместим.
- Окна/UI Windows → заменяем на Qt (PHASE 1).
- Интеграция с LLM (в VPet есть ChatGPT-настройки) — свою реализацию с нуля (PHASE 5).

4. README_en.md может дословно повторять условия лицензии анимаций — сверить перед принятием решения об использовании.
