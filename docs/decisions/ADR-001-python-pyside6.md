# ADR-001: Python + PySide6

**Статус:** принят (2026-10-08)

## Контекст

Нужен стек для кроссплатформенного 2D Desktop Pet с прозрачными окнами, работающий на Ubuntu x86-64 и Raspberry Pi OS ARM64.

## Рассмотренные альтернативы

- **Electron / WebView**: запрещён концепцией (RAM, ARM64, вес).
- **GTK (PyGObject)**: есть в системе, но спрайтовая анимация и всегда-поверх-окна требуют больше ручной работы; экосистема Qt богаче для анимаций/таймеров.
- **C++ + Qt**: производительнее, но замедляет итерации; концепция指定 Python.
- **Tkinter**: нет нормальной alpha-прозрачности и always-on-top политики.

## Решение

Python ≥ 3.11 + PySide6 (Qt for Python), как указано в концепции.

## Причины

- Концепция прямо указывает PySide6.
- Официальные wheels для x86-64 и aarch64 (Linux); запасной вариант — apt `python3-pyside6` (6.10.2) для ARM64.
- Qt: прозрачные окна, таймеры, сигналы/слоты, QThread для фоновых задач, pytest-qt для тестов.

## Последствия

- Тяжёлая зависимость (~100+ MB) — приемлемо для 64 GB dev и 4 GB RPi.
- Нужно следить за производительностью Qt в IDLE на RPi.

## Ограничения

- Wayland-особенности Qt требуют проверки (ADR-002).
- Версия Qt в apt и pip может расходиться — фиксировать версии в зависимостях.
