# docs/PHASE1_PLAN.md — требования к минимальному GUI-прототипу и план PHASE 1

**Цель PHASE 1:** Minimal Desktop Pet — прозрачное окно с тестовым персонажем, который перетаскивается мышью, поверх всех окон, корректно завершается.

## Требования к минимальному GUI-прототипу

### Функциональные

- **FR-P1.1** Прозрачное frameless-окно: `Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint`, `WA_TranslucentBackground`, без прямоугольного фона (alpha=0 вокруг персонажа).
- **FR-P1.2** Отображение тестового спрайта — временное изображение (PNG с alpha), отцентровано в окне. Свою графику рисовать не нужно — достаточно простой заглушки (сгенерировать простой PNG скриптом или взять свою иллюстрацию).
- **FR-P1.3** Перетаскивание: `mousePressEvent` → `mouseMoveEvent` (глобальные координаты `QCursor.pos()`/`event.globalPosition()`), окно следует за курсором без «отрыва».
- **FR-P1.4** Ограничение экраном: координаты окна зажимаются в рабочую область `QScreen.availableGeometry()` (минимум X/Y и максимум с учётом размера окна).
- **FR-P1.5** Контекстное меню (ПКМ): минимум пункт «Выход» → корректное завершение.
- **FR-P1.6** Always-on-top: флаг `WindowStaysOnTopHint` + проверка фактического поведения на Wayland/X11.
- **FR-P1.7** Корректное завершение: закрытие меню, SIGINT/SIGTERM — выход 0, без зомби.

### Нефункциональные

- **NF-P1.1** Запуск: `python -m microchel.desktop.main` (или точка входа `scripts/run_pet.sh`), старт < 3 с.
- **NF-P1.2** Не блокировать event loop: таймер 30+ FPS для будущих анимаций уже заложен, но в PHASE 1 достаточно idle-отрисовки.
- **NF-P1.3** Память: фоновое потребление минимально; никаких утечек при перетаскивании.
- **NF-P1.4** Не требовать системных пакетов: только PySide6 из venv.
- **NF-P1.5** XDG_SESSION_TYPE не предполагать: логировать выбранный Qt platform plugin при старте.

### Явно НЕ входит в PHASE 1

Анимации/спрайт-плеер, FSM, агент, LLM, голос, мониторинг, автозапуск, масштабирование.

## План PHASE 1 (шаги)

1. **Окружение**: `python3 -m venv .venv`, `pip install -e ".[dev]"`, smoke-тест `import PySide6` (версия, Qt runtime). Зафиксировать результат в STATUS.md.
2. **Каркас приложения**: `src/microchel/desktop/main.py` — точка входа, `PetWindow(QMainWindow/QWidget)` в `src/microchel/desktop/window.py`. Логирование (`common/logging_config.py`), чтение `XDG_SESSION_TYPE`.
3. **Тестовый спрайт**: сгенерировать `assets/characters/test/test_idle.png` (скриптом `scripts/make_test_sprite.py` — свой материал, лицензия не вопрос) + загрузка в окно.
4. **Перетаскивание + зажим координат** (FR-P1.3, FR-P1.4).
5. **Прозрачность и always-on-top** (FR-P1.1, FR-P1.6) — проверить на Wayland; если always-on-top не работает нативно → варианты: `QT_QPA_PLATFORM=xcb` (XWayland), layer-shell протокол (не в Qt из коробки — отдельный ADR). Результаты — в TESTING.md и ADR-002.
6. **Контекстное меню и завершение** (FR-P1.5, FR-P1.7).
7. **Тесты**: юнит (зажим координат, логика ввода — вынести в чистые функции), pytest-qt для ввода; ручные сценарии 1–6 из TESTING.md.
8. **Документация**: STATUS/DEVELOPMENT_LOG/ROADMAP/CHANGELOG обновить; ARCHITECTURE — раздел «что реализовано».
